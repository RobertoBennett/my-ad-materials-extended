# My Ad Materials Extended

## Описание
Расширение для плагина My Ad Materials с мультипользовательским доступом, экспортом статистики и рассылкой отчетов. Плагин добавляет расширенную функциональность к основному плагину управления рекламными материалами.

## Основные характеристики
- Мультипользовательский доступ к рекламным материалам
- Экспорт статистики в различных форматах
- Автоматическая рассылка отчетов по email
- Интеграция с родительским плагином My Ad Materials
- Удобная панель управления в админке

## Зависимости
- Требуется установленный и активированный плагин **My Ad Materials**
- Родительский плагин должен быть установлен в папке `/wp-content/plugins/my-ad-materials/`

## Установка
1. Убедитесь, что установлен и активирован плагин My Ad Materials
2. Загрузите файл `my-ad-materials-extended.php` в папку `/wp-content/plugins/`
3. Активируйте плагин через меню 'Плагины' в WordPress
4. Настройте доступ через раздел "Рекламные материалы" → "Настройки отчетов"

## Компоненты плагина
### 1. Мультипользовательский доступ
- Управление правами доступа для разных пользователей
- Настройка уровней доступа к рекламным материалам

### 2. Экспорт статистики
- Экспорт данных в форматах CSV, Excel
- Настраиваемые периоды отчетности
- Фильтрация данных перед экспортом

### 3. Рассылка отчетов
- Автоматическая отправка отчетов по расписанию
- Настройка подписок для пользователей
- Кастомизируемые шаблоны email-сообщений
